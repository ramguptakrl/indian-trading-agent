TRADE BRAIN — PERMANENT SANITIZED LEARNING LOG
================================================

Purpose
-------
This repository file records durable, sanitized project learning checkpoints: experiments,
validation results, engineering discoveries, rejected ideas, evidence-boundary decisions,
and interpretation summaries that should survive individual local/runtime sessions.

This file MUST NEVER contain API secrets, access tokens, request tokens, passwords, cookies,
authorization headers, broker credentials, or hidden chain-of-thought.

Runtime detail belongs in the append-only local TXT audit under:
  %USERPROFILE%\.tradingagents\tradebrain\audit_txt\

Product boundary
----------------
- Modeled trader: RESIDENT_INDIAN.
- Active modes: INTRADAY and SWING.
- Zerodha Kite role: MARKET_DATA_ONLY.
- Automatic broker order execution: DISABLED.
- Hard safety rules: protected; never auto-optimized.
- Learning means evidence collection/replay/calibration, not autonomous LLM-weight training.
- Challenger/soft-parameter promotion requires explicit human approval.
